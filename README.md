## Featured Projects

### [TrackAS – Smart Attendance System](https://github.com/kumarshubham20/Attendance-System)
A QR-code and geolocation-based attendance platform that lets lecturers run attendance sessions and students check in securely.

- Lecturers generate a unique **QR code** per class session, secured with a session token
- Student location is verified with the **Haversine formula**; attendance is recorded only within **20 m** of the classroom
- **PostgreSQL via Supabase** with `classes` and `attendance` tables, protected by **Row Level Security (RLS)** policies
- Lecturer dashboard with attendance history, filtering, and **Excel export**
- Interactive class-location picker built with **Leaflet maps**
